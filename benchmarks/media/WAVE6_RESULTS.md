## Local interface proposal for #2/#3

- prepare(source_path, provenance, rights, start_frame, frame_count) returns PCM16 bytes and a review receipt. Caller must provide verified rights for source, derivative and advertising sync and an authorized local source path. 48 MiB source bound, mono/stereo, 8–48 kHz, WAV/WAVEX PCM16/24/32 or float/double, 3–120s source, 3–60s sample-frame selection. Reads original once, rejects truncated/nonfinite/out-of-range selected samples and silence. Only selected samples are decoded/validated; no claims about unused source sections. Provenance kind synthetic-fixture, user-supplied, or generated-unverified (requires source ID, provider, revision). No label can assert genuine inference; inference_verified always false. Rights assertions are not independent legal proof. No model, provider, network service or credential access.
- Uses FFmpeg loudnorm measurement, constant gain up to +12 dB, 50ms/150ms selection fades and PCM16 quantization. Target -16 LUFS, conservative -2.2 dBTP headroom; preview rejects >-2 dBTP or >-15.8 LUFS. May be quieter for highly dynamic sources. No compression/limiting, no invented lyrics/vocals. Final AAC measured separately; reject >-1 dBTP or >-15.5 LUFS before exclusive output publication. These are engineering limits, not platform-specific mastering guarantees.
- Caller writes prepared bytes into a private local workspace, bind_soundtrack(board, receipt, project_id), then bind_timing(board, preview_path) computes exact beat timeline through existing renderer's Librosa algorithm. Reviewer must inspect preview and approve using existing approve(board, reviewer, project_key(master_key, project_id)). render_project checks HMAC, project ID, source and prepared byte hashes, explicit rights and exact reviewed timeline, invokes existing Wave 5 incremental renderer (asset hashes, evidence, frame bounds, full decode QC), measures final AAC, and publishes via same-filesystem hard link only when gates pass. No automatic approval except original synthetic demo.
- Project key derived with domain-separated HMAC from caller-protected master key + trusted globally unique project ID; project cache directory separately derived with HMAC. Same project can reuse clips; distinct projects do not share cache keys/dirs. Root/child directory mode 0700 checked on POSIX; symlinks rejected at root/child. Not a multi-tenant service, authentication, ACL enforcement on Windows, protection against hostile local process, encryption or production authorization; trust caller paths/project IDs and review source receipt. No signed source attestation from provider, production upload service, aggregate project cache quota, cleanup/revocation service or user UI. Existing per-project clip limits inherited. Three scenes of four detected beats, 24fps, <=480 output frames. Insufficient/invalid beats fail closed; no guarantee of musical alignment for arbitrary real music. Preview timing recomputed, not silently adjusted; new review required for changes. Existing Wave 5 renderer untouched.
