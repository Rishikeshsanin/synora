# Delivery sequence

Phase 0: agent ownership, contracts, local tooling and smoke CI.
Phase 1: parallel frontend, backend, music provider adapter, devops and QA. Media agent works only on local offline prototype and contracts proposal; no paid video or production integration.
Phase 2: integrate backend + frontend + fixture provider; verify job submission, progress, playback, download, isolation, failure and retry.
Phase 3: real music benchmark after approved budget/access: same prompts, duration, latency, artifact validity, musical coherence, instruction adherence, cost, license. Include Telugu/Hindi/English and instrumentals. Do not claim full control unsupported by model.
Phase 4: real music release gates: end-to-end verification, auth/RLS, private media, billing safeguards, mobile/accessibility, CI and production smoke; production deployment requires lead approval.
Phase 5: M2 concept generation, approved storyboard, actual product fidelity, soundtrack reuse, beat-synced rendering, exports and ad claims review.

Lead reviews PRs in dependency order; QA independently verifies latest integrated commit. No paid services activated without owner approval. Document all blockers and exact continuation steps in GitHub.
